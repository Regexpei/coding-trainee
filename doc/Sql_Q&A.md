### 一、limit 500000, 10 和 limit 10 速度一样快？

> `limit 500000, 10` 表示从结果集中跳过前500000行，然后返回接下来的10行数据。
> 
> `limit 10` 表示从结果集中取前10条数据。 

**速度差异主要取决于两个因素**：
1. 数据量，如果数据量比较大，`limit 500000, 10`需要跳过大量的数据才能返回结果。 
2. 索引，如果表中有合适的索引，`limit 500000, 10`可以通过索引直接定位到指定行号返回结果。

无论什么情况下，`limit 10`的速度都比`limit 500000, 10`快，并且随着数据量增加，`limit 500000, 10`查询速度会更慢。

**优化**：
1. SQL语句层面：使用子查询的结果作为过滤条件，从指定位置行的主键开始获取10行数据。（优化程度并不高）
    ```sql
    SELECT
        *
    FROM
        `coding_trainee`.`tb_user` 
    WHERE
        `id` >= ( SELECT `id` FROM `coding_trainee`.`tb_user` ORDER BY `id` LIMIT 1 OFFSET 499999 ) 
    ORDER BY
        `id` 
        LIMIT 10;
    ```
2. 业务层面：避免使用大偏移量查询数据
