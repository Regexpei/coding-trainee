## 简介

InfluxDB 是一个用 Go 语言编写的时序数据库，与传统关系型数据库相比，它对时序数据场景有专门地优化。
当前，时序数据库主要运用在运维、IOT 领域，常用它完成指标的实时检测。

## 基本概念
- **Bucket**：A bucket is a named location where time series data is stored. All buckets have a Retention Period, a  duration of time that each data point persists.
  > 一个存储桶（Bucket）是一个命名位置，用于存储时间序列数据。所有的存储桶都有一个保留期（Retention Period），即每个数据点持续存在的时间段。
  > 
  > **简单说，存储桶就是用来存储数据的地方（类似关系型数据库中的数据库），每个存储桶都有自己的保留期，保留期越长，数据存活的时间越长。**

- **Telegraf**： Telegraf is an agent written in Go for collecting metrics and writing them into InfluxDB or other possible outputs.
  > Telegraf 是一个用 Go 语言编写的代理，用于收集指标并将其写入 InfluxDB 或其他可能的输出。

- **Scraper**：Scrapers collect data from multiple targets at regular intervals and to write to a bucket.
  > Scraper 是一个用于主动抓取 Prometheus 或其他数据源中 metrics 数据的组件，能够收集来自多个目标的数据，并定期写入存储桶。
